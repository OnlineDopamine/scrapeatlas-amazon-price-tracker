Amazon Price Tracker

A small open-source script that searches Amazon or watches ASINs and appends price snapshots to a CSV. Data comes from the ScrapeAtlas public-data API, so there are no proxies or HTML selectors to maintain.

Run it

pip install requests
export SCRAPEATLAS_API_KEY=sa_live_...
python price_tracker.py --query "wireless earbuds"
python price_tracker.py --asin B09DT48V16

The request

curl 'https://api.scrapeatlas.com/v1/amazon/product-search?query=wireless+earbuds&country=US' \
  -H 'x-api-key: YOUR_API_KEY'

What comes back (sample)

ASINTitlePriceWasRating

Notes

  • 1 credit per successful request; failed requests cost 0. New accounts get 100 free credits.
  • Pass pagination.next_cursor back as cursor for more pages.
  • Call from a server or script; the API doesn't allow browser CORS from other sites.

Docs: scrapeatlas.com/docs
